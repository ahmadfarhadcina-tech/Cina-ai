GETTING STARTED

Introduction

Cina AI provides a developer-focused API for integrating artificial intelligence into websites, mobile applications, services and other software.

The public API uses versioned endpoints beginning with /v1.

AUTHENTICATION

API keys

Requests to protected Cina AI endpoints require an API key.

HTTP 
Authorization: Bearer fc_live_your_key
Security: Never expose a production API key in browser-side code or public repositories.
QUICKSTART

Make your first request

A basic chat request uses the /v1/chat endpoint.

POST /v1/chat 
POST https://api.cina.ai/v1/chat

Authorization: Bearer fc_live_your_key
Content-Type: application/json

{
  "model": "cina-1",
  "messages": [
    {
      "role": "user",
      "content": "Hello, Cina"
    }
  ]
}

Response 

{
  "id": "chat_01c...",
  "object": "chat",
  "model": "cina-1",
  "output": "Hello! How can I help?",
  "usage": {
    "input_tokens": 8,
    "output_tokens": 7,
    "total_tokens": 15
  }
}
API REFERENCE

List models

Retrieve the models currently available to your API account.

GET /v1/models 
{
  "object": "list",
  "data": [
    {
      "id": "cina-1",
      "object": "model",
      "status": "available"
    }
  ]
}
CHAT

Chat

Send a sequence of messages to a Cina AI model and receive a generated response.

POST /v1/chat

Request body

model The model identifier.
messages Conversation messages.
GENERATION

Generate

Generate text from a direct prompt.

POST /v1/generate 
{
  "model": "cina-1",
  "prompt": "Explain artificial intelligence simply."
}
USAGE

Usage

Usage information allows applications and developers to monitor API consumption.

GET /v1/usage
